10-printed-bolt

An M8 x 30 hex bolt with a modelled thread, standing on its head to print (the parts library). Check: cad model dfm "$ID" --process printing --material petg

Open in playgroundView on GitHubAll examples

#Source

Run it with cad run examples/dogfood/10-printed-bolt.ts.

// An M8 x 30 hex bolt with a modelled thread, standing on its head to print (the parts library).
// Check: cad model dfm "$ID" --process printing --material petg
import { model, parts } from "@cad/sdk";
// printed standing on its head
await model("modelled_bolt", () => parts.hexBolt("M8", 30, { thread: "modelled", material: "petg", color: "#3182ce" }).rotateX(180))();
