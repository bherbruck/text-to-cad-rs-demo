#Mechanisms: joints, poses and animations

Read this file when a model moves: a hinge, a slide, an arm, gears that turn together, a lid that opens; or when the person wants it posed, checked for clashes through its travel, or animated in a GLB. A robot description for simulation (URDF, MJCF, SRDF) is the robot-simulation skill's.

#Joints

Build every part where it stands: the geometry is the mechanism at each joint's default (its as-built value, 0 unless given). An assembly declares its joints in its third argument; nothing about a joint changes the built geometry or a STEP.

import { assembly, box, model, revolute } from "@cad/sdk";

export const lidBox = model("lid_box", () => {
  const tray = box(60, 40, 30, { align: ["center", "center", "min"] }).label("tray");
  const lid = box(60, 40, 4, { align: ["center", "center", "min"] }).translate(0, 0, 30).label("lid");
  return assembly("box", [tray, lid], {
    joints: [revolute("hinge", { parent: tray, child: lid, axis: { origin: [0, 20, 34], dir: "-X" }, limits: [0, 110] })],
    poses: { closed: { hinge: 0 }, open: { hinge: 100 } },
  });
});
JointMoves the childValue
revolute(name, { parent, child, axis, limits?, default?, effort?, velocity? })turns about axis, right-handed about its directiondegrees
prismatic(name, { … same })slides along axismm
cylindrical(name, { …, slideLimits?, slideDefault? })turns and slides on one axis: <name>.turn, <name>.slidedegrees, mm
ball(name, { parent, child, center, z?, limits? })turns about three axes: <name>.x, .y, .zdegrees
fixed(name, { parent, child })fastens the child to the parent's link–
  • parent and child are parts or assemblies of this assembly, or a label or / path

    ("arm/forearm"); the child moves with everything below it.

  • axis is in the assembly's coordinates as built: "Z", a direction, or { origin, dir }.
  • Chains: a joint whose parent rides on another joint's child moves with it (a forearm on an

    upper arm). Each part is placed by at most one joint; a loop is refused.

  • effort (N·mm, or N for a slide) and velocity (deg/s, or mm/s) are the actuator's, written into

    robot descriptions.

  • cad model inspect "$ID" lists the joints, their limits and the poses.

#Poses

poses names joint values ({ open: { hinge: 100 } }; joints not named stay as built). Every command that draws or measures takes --pose (a pose's name, joint=value,..., or JSON):

cad model snapshot "$ID" tmp/open.png --pose open
cad model snapshot "$ID" tmp/half.png --pose hinge=55

The viewer shows a slider per joint and a button per pose.

#Couplings

Joints that move together: couple(leader, follower, ratio, offset?) makes follower = offset + ratio · leader. Gears are -r1/r2; a rack and pinion 2πr/360 mm per degree; a screw its lead per 360 degrees. Pass them as couplings: [...]. A follower is never posed directly.

#Check the travel

cad model ranges "$ID"                              # each joint's stops, found from the geometry
cad model interference "$ID" --pose closed --pose open
  • cad model ranges moves each joint until its parts meet and reports the range to write into its

    limits, what stops it and any clash (--joint, --step, --clearance). It changes nothing: write the limits into the code.

  • Check interference at each end of each joint's travel and in between (--pose hinge=90): a

    hinge whose axis points the wrong way reaches the right closed pose through the part, and only a mid-travel pose or a snapshot shows it. Flip dir ("-X" for "X") to swing the other way.

  • A snap fit's barb meets its catch before the closed pose: ranges says so (the stop short of

    closed). That is the snap, which flexes; report it, don't shorten the travel.

#Animations

animation(name, seconds, { loop? }) builds a clip that is baked into every GLB the model exports:

const show = animation("showcase", 4, { loop: true })
  .pose({ 0: "closed", 1.5: "open", 3.5: "closed" })   // the mechanism, eased between keys
  .stagger(["feet/foot_1", "feet/foot_2"], { by: [0, 0, -20], step: 0.5, start: 0.5 })
  .rotate("latch", { axis: "Z", turns: 2, start: 1, end: 3, interpolation: "linear" })
  .hide("latch", 3);
assembly("box", [tray, lid, latch, feet], { joints, poses, animations: [show] });

Methods: pose, translate, rotate, scale, explode, stagger, hide, show. Parts are a label, a path, an assembly or a glob (feet/*). A track does nothing before its first key and holds its last; times are seconds. Snapshots and STEP files show the model as built.
