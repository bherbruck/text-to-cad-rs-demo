#Exports

Read this file when the person asks for STEP, STL, 3MF, GLB, OBJ, BREP or DXF files, a 2D profile or flat pattern, or a file converted to another format.

#A file is an action

A file is written from the document the server holds, when asked, each destination by its suffix. No code changes and nothing rebuilds:

cad model export "$ID" out/bracket.step out/bracket.stl out/bracket.glb
  • Run the model first: an export writes the document as its last successful build left it.
  • Folders are created as needed; an existing file is replaced.
  • A written file is a detached copy: it changes only when exported again. Give the person its

    path.

#Formats

SuffixHoldsFor
.step / .stpExact B-rep, assembly tree, part names and coloursCAD exchange, machining, the default deliverable
.brepThe kernel's native B-repReloading into OCCT tools
.stlTriangles, one mesh3D printing (slicers)
.3mfTriangles per part, with names and colours3D printing with parts and colours
.glbTriangles per part, with colours and the assembly treeWeb viewers, rendering, AR
.objTrianglesOlder mesh tools
.dxf2D lines, circles, arcsLaser, waterjet, router (below)
.pdf / .svgA dimensioned engineering drawingA shop's drawing (drawings)

When the person names no format, STEP is the one that keeps the geometry exact; add an STL or 3MF when the part is going to a printer.

#Mesh tolerance

--tolerance MM (chordal deviation) and --angle DEG (angular deviation) mesh .stl, .3mf, .glb and .obj finer or coarser:

cad model export "$ID" out/knob.stl --tolerance 0.01 --angle 5     # a print with fine fits
cad model export "$ID" out/preview.glb --tolerance 0.2              # a light web preview

The defaults suit viewing. For a print with press fits or small holes, use 0.01–0.02 mm. They apply to mesh files only: an export naming a .step, .brep or .dxf with them is refused (exit 2) and writes nothing, so export the exact formats in a separate command.

#Exporting from a script

The handle a model call returns exports the same way, paths relative to the working directory:

if (import.meta.main) {
  const h = await plate();
  if (process.argv.includes("--export")) {
    await h.export("out/plate.step", "out/plate.stl", { tolerance: 0.02 });
  }
}
cad run src/plate.ts --export

Keep a plain run free of file writes: write files when the person asked for them, behind an argument like this, or with cad model export.

#One part of an assembly

An export is a whole document. For one part alone, export that part's own model (the reason each part of an assembly gets a model of its own, assemblies):

cad model export "$LID_ID" out/lid.stl

#DXF and 2D profiles

A DXF is written from geometry that lies on z = 0: a profile on Plane.XY (or wires). Its edges become LINE, CIRCLE and ARC entities; splines become polylines. A 3D solid exports its section at z = 0.

Model the flat outline once and use it for both the 2D model and the solid:

import { circle, model, rect, slot } from "@cad/sdk";

function outline() {
  return rect(120, 80, { radius: 6 }).hole(
    circle(2.75).at(-52, -32), circle(2.75).at(52, -32), circle(2.75).at(52, 32), circle(2.75).at(-52, 32),
    slot(40, 8).at(0, 20),
  );
}

export const plate2d = model("plate_2d", () => outline());                         // export this as .dxf
export const plate = model("plate", () => outline().extrude(3).label("plate"));     // and this as .step

if (import.meta.main) { await plate2d(); await plate(); }
cad model export "$PLATE_2D_ID" out/plate.dxf
cad model snapshot "$PLATE_2D_ID" out/plate_top.png --camera top
  • Draw on Plane.XY at z = 0. A profile on another plane, or moved off z = 0, is not a drawing.
  • Bend lines and other marks are parts of their own beside the cut profile:

    assembly("flat", [outline.label("cut"), polyline([[x, -w / 2, 0], [x, w / 2, 0]]).label("bend_1_up_90")]). Each part is a layer of its own, named by its path upper-cased (BLANK_BEND_1_UP_90), so name bend lines for what they are; still tell the shop which layer bends which way.

  • A DXF is in millimetres. Say so to the person: some cutting services assume inches.
  • A sheet part with bends has no flat pattern here: model the flat blank as a 2D profile.
  • Check a DXF with a --camera top snapshot of its model; count the holes and slots against the

    request.

#Converting a file

cad viewer FILE --json opens a STEP or STL as a document and prints its id and page; that id exports like a model's:

cad viewer vendor/motor.step --json      # → [{ "file": "…", "id": "…", "url": "…" }]
cad model export "$ID" out/motor.glb

A mesh (STL) has no B-rep: it converts to other mesh formats, not to a meaningful STEP or DXF.
