#@cad/sdk modeling

Read this file when constructing or repairing geometry: which call makes what, where it lands, and the pitfalls. Models and how they run are models; picking edges and faces is selectors.

#Conventions

  • Millimetres and degrees, +Z up. Points are [x, y, z]; points in a workplane are [u, v].
  • Every method returns a new shape and leaves the original untouched; shapes can be reused freely.
  • Axes are "X", "Y", "Z" (or "-Z" …), a direction [x, y, z], or { origin, dir }.
  • Planes are "XY", "XZ", "YZ", a Plane, or { origin, normal }.
  • Everything is imported from "@cad/sdk".

#Solids

CallMakes
box(x, y, z, { align })A box, centred on the origin
cylinder(r, h, { align })A cylinder along Z, centred
cone(r1, r2, h, { align })A cone or frustum along Z: r1 at the bottom, r2 at the top (either may be 0)
sphere(r)A sphere at the origin
torus(R, r)A ring around Z: ring radius R, tube radius r

align places the bounding box on the origin per axis: "min", "center" (default) or "max", one for all axes or one per axis.

box(40, 20, 6, { align: ["center", "center", "min"] })   // sits on z = 0
box(40, 20, 6, { align: "min" })                         // corner at the origin, grows to +X +Y +Z
cylinder(5, 20, { align: ["center", "center", "min"] })  // stands on z = 0

#Profiles and workplanes

A profile is a closed planar region (an outer loop and holes) on a workplane, in the plane's own [u, v] coordinates. It is a shape (it can be exported as DXF, moved, booleaned) and it turns into a solid by extrude, revolve, sweep or loft.

CallMakes
rect(w, h, { radius })A rectangle centred on the plane's origin; radius rounds its corners
circle(r)A circle centred on the plane's origin
polygon([[u, v], …])A closed polygon through the points
regularPolygon(r, n)A regular n-gon, circumradius r, a vertex on +u
slot(length, width)A stadium length long overall along u
sketch(plane)…close()Any outline of lines, arcs and splines (below)

Each takes { plane } (default Plane.XY). On a fresh profile:

  • .at(u, v) moves it within its plane: circle(3).at(20, 10).
  • .turn(degrees) turns it within its plane about the plane's origin: turn first, then .at

    (slot(14, 5).turn(90).at(17, 26) is a slot along v).

  • .onPlane(plane) draws the same 2D outline on another plane.
  • .hole(...profiles) cuts the profiles out: rect(60, 40).hole(circle(4).at(-20, 0), circle(4).at(20, 0)).
Planeu (xDir)v (yDir)normal (extrude direction)
Plane.XY+X+Y+Z
Plane.XZ+X+Z-Y
Plane.YZ+Y+Z+X

Plane.XY.offset(10) is the plane at z = 10 (moved along its normal); Plane.XZ.moveTo([10, 0, 0]) puts the origin at a point; .turn(deg) spins it about its normal; .flip() reverses the normal; Plane.fromNormal(origin, normal) makes one from a point and a direction; new Plane(origin, xDir, normal) gives full control.

#Sketching a path

sketch(plane) draws in [u, v], one segment at a time, from moveTo. Every call returns a new sketch.

CallAdds
.moveTo(u, v)The start (first call only)
.lineTo(u, v) / .line(du, dv)A line to a point / by an offset
.hLine(du) / .vLine(dv) / .hLineTo(u) / .vLineTo(v)Horizontal and vertical lines
.polarLine(length, deg)A line at an angle from +u
.arcTo([mu, mv], [u, v])A three-point arc through a middle point
.tangentArcTo(u, v)An arc to a point, tangent to the previous segment
.splineTo([u, v], …)A spline through the points, ending at the last
.close()A line back to the start if needed: a profile
.wire()The open path as a wire (a sweep path)
// An L-section on XY, extruded 50 along Z
const angle = sketch().moveTo(0, 0).hLine(30).vLine(4).hLineTo(4).vLineTo(30).hLineTo(0).close().extrude(50);

// A knob's half-section on XZ (u = radius, v = height), spun about Z
const knob = sketch(Plane.XZ)
  .moveTo(0, 0).hLineTo(15).vLineTo(13).tangentArcTo(12, 16).hLineTo(0)
  .close()
  .revolve();

One sketch is one loop. For holes, draw each loop as its own profile and combine with .hole().

#Profile to solid

CallMakes
profile.extrude(h)A prism h along the profile's normal (negative: the other way)
profile.extrude([x, y, z])A prism along a vector
profile.extrude(h, { midplane: true })Centred on the plane, total length h
profile.extrude(h, { taper: 3 })Sides drawn in by 3° (a draft)
profile.revolve(deg = 360, axis = "Z")A solid of revolution about an axis through the origin, or { origin, dir }
profile.sweep(path, { binormal })The profile carried along a wire
loft([p1, p2, …], { ruled, solid })A skin through sections in order
helix(r, pitch, h, { left })A helix wire around Z from [r, 0, 0] to height h
polyline([[x, y, z], …]), spline([[x, y, z], …])3D path wires
// Spring: a circle square to the helix's start (tilted by the helix angle, so the ends are
// clean caps), swept with a fixed binormal (no twist)
const lead = (Math.atan2(4, 2 * Math.PI * 10) * 180) / Math.PI;
const wire = circle(0.6, { plane: Plane.XZ.moveTo([10, 0, 0]) }).rotate({ origin: [10, 0, 0], dir: [1, 0, 0] }, lead);
const spring = wire.sweep(helix(10, 4, 40), { binormal: "Z" });

// Square-to-round transition
const duct = loft([rect(40, 40, { radius: 4 }), circle(14, { plane: Plane.XY.offset(50) })]);

// Bent rod along a path
const rod = circle(3, { plane: Plane.YZ }).sweep(polyline([[0, 0, 0], [40, 0, 0], [40, 0, 30]]));
  • Revolve: draw the half-section on Plane.XZ with u ≥ 0 (u is the radius); a profile that

    crosses the axis makes an invalid solid.

  • Sweep: put the profile at the path's start, square to the path (a helix starts at [r, 0, 0]

    heading +Y and climbing at atan(pitch / 2πr), so Plane.XZ.moveTo([r, 0, 0]) tilted by that angle about X); a profile at a slant leaves sliver faces at the ends. Sharp corners in a polyline path pinch; round them with a spline or arcs.

  • Loft sections should have the same number of edges for a clean skin; a circle to a

    rectangle works, but ruled lofts need matching loops.

#Booleans

CallMakes
a.fuse(b, c, …) (add, union)The union
a.cut(b, c, …) (subtract)a minus every tool
a.intersect(b, …)What they share
fuse(a, b, …)The union, as a function
compound(a, b, …)Kept as separate solids in one shape, no boolean (fast for disjoint pieces)

Arrays are flattened, so a.cut(hole.polarCopies(6), slot) works.

#Transforms

s.translate(10, 0, 5)           // or .translate([10, 0, 5]), .move(...)
s.rotate("Z", 45)               // about the Z axis through the origin
s.rotate("X", 90, [0, 0, 10])   // about a parallel axis through a point
s.rotateX(90)                   // also rotateY, rotateZ
s.scale(2)                      // about the origin; .scale(2, center)
s.mirror("YZ")                  // the mirror image only: s.fuse(s.mirror("YZ")) for both halves

Rotations follow the right-hand rule. Transforms apply in the order written: .rotateZ(90).translate(10, 0, 0) turns in place then moves; the other order swings the shape around the origin.

#Features

CallDoes
s.fillet(edges, r)Rounds the selected edges
s.chamfer(edges, d)Bevels the selected edges
s.shell(openFaces, t)Hollows the solid, removing openFaces; t < 0 walls grow inward (the usual), t > 0 outward. shell(null, -2) hollows with no opening
s.offset(d)Grows (> 0) or shrinks (< 0) every face by d
s.section(plane)The cross-section where a plane cuts the solid (faces)
s.split(plane, keep)Cuts by a plane; keeps "above" (the normal's side), "below" or "both"
box(40, 30, 20).fillet("|Z", 3).fillet(">Z", 1)       // vertical edges, then the top's edges
box(60, 40, 25).shell(">Z", -2)                        // an open-top box with 2 mm walls
part.split(Plane.XY.offset(5), "below")                // what lies below z = 5

Selectors are strings (">Z", "|Z and >X", "%CIRCLE"), builders (sel.near([x, y, z])) or indices [3, 7]: see selectors.

#Patterns

CallReturns
s.linearCopies(n, [dx, dy, dz])n copies, each a step further (the first is s)
s.polarCopies(n, { degrees = 360, axis = "Z", center })n copies about an axis; spread evenly for 360°, else first at 0 and last at degrees
s.gridCopies(nx, ny, dx, dy, { center = true })A grid in X and Y, centred on s
linearPattern, polarPattern, gridPattern (methods or functions)The same copies fused into one shape
const plate = box(80, 60, 4).cut(cylinder(2.5, 10).gridCopies(2, 2, 70, 50));
const hub = disk.fuse(spoke.polarCopies(5));
const knurl = body.cut(cylinder(0.8, 40).translate(15.3, 0, 0).polarCopies(30));

Copies are an array: pass them to cut, fuse or assembly directly. Copies of a labelled part keep its label (and in an assembly are told apart by their path).

#Parts, colour and material

const lid = body.label("lid", { color: "#d8dde3", material: "petg" });
const knob = body.color("#202124");                      // a part labelled with the model's name
const custom = body.label("gasket").material({ name: "epdm", density: 1.15 });
  • Colours are "#rrggbb", "#rgb" or [r, g, b] integers 0–255 (sRGB).
  • A grade after a preset's name is kept as written and weighs as its family: "aluminium 6061",

    "stainless 316", "steel s355" (the stress study and the manufacturing check read the name).

  • Material presets (density g/cm³): aluminum 2.70, steel 7.85, stainless 8.0, brass 8.5,

    copper 8.96, bronze 8.8, titanium 4.43, cast_iron 7.2, pla 1.24, petg 1.27, abs 1.04, asa 1.07, nylon 1.14, pc 1.20, acrylic 1.18, pom 1.41, tpu 1.21, hdpe 0.95, ptfe 2.2, rubber 1.1, oak 0.75, pine 0.5, plywood 0.6, mdf 0.75, glass 2.5, mild_steel 7.85, stainless_steel 8.0, galvanized 7.85, pp 0.90, pe 0.95, ldpe 0.92, pmma 1.18, ps 1.05, pbt 1.31, peek 1.30, pei 1.27, pvc 1.38, lcp 1.40, pps 1.35, nylon_gf 1.36, pc_abs 1.15. Anything else: { name, density }.

  • A material gives the part a mass (grams) in the summary and inspection.
  • Labels may not contain / or #; they name the part in references.

#Pitfalls

  • Primitives are centred by default. cylinder(r, h) runs from -h/2 to h/2: a hole tool

    translated as if it started at z = 0 stops halfway and cuts a blind pocket, silently. Give the tool { align: ["center", "center", "min"] } or size it to pass through everything, and look at the result with --display hidden-line (a blind cut shows dashed).

  • Shell after rounds larger than the wall. An inward shell(..., -t) offsets every round by

    t: a fillet of radius t or less fails on OCCT (shell failed: StdFail_NotDone). Make the rounds larger than the wall, or shell first and round the outside after.

  • Slivers from cuts that nearly meet. Two cut tools that end within a hair of each other (a slot

    stopping 0.02 mm under a channel's roof, a groove running through a floor's inside round) leave a sheet of material too thin to make: cad model dfm names it (printing.skin_layer, printing.wall_* at a few hundredths of a millimetre). Run tools past one another.

  • Coplanar booleans. A tool that ends exactly on the face it cuts can leave a skin or fail.

    Make cutting tools longer than what they cut (cylinder(r, t * 2) through a plate of t), and overlap fused pieces slightly rather than touching them face to face.

  • Fillet last, and largest first. Fillet after the booleans that create the edges; a radius

    larger than an adjacent face fails. When a fillet fails, try a smaller radius or fewer edges, and check what the selector matched (selectors).

  • Select after the operation that made the edges. Selectors run on the shape they're called

    on, so a.cut(b).fillet("|Z", 1) sees the cut's edges; there is nothing to hold stale.

  • Plane.XZ's normal is -Y. A profile on XZ extrudes toward -Y; use a negative amount or

    .flip() the plane for +Y.

  • mirror returns only the image; fuse it with the original for a symmetric whole.
  • Shell sign. Negative thickness keeps the outside dimensions (walls grow inward).
  • A profile is not a solid. rect(…) alone is a face; booleans between faces and solids

    rarely mean what you want. Extrude first.

  • Units. Everything is millimetres. A part that comes out 25.4 times too big or small came

    from inches.

  • Limits. Every number is within ±1e6 (1 km), a helix takes at most 10 000 turns, a model at

    most 200 000 ops and one op 1 MB of arguments, and a selector string nests at most 48 deep. The SDK refuses a call past one at its own line, with the server's wording (docs/security.md).
