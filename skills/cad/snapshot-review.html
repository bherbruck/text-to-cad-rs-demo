#Snapshots

Read this file when choosing pictures to review a model or a file. Which pictures a change calls for is Check each change; this file is what a snapshot can draw.

#Contents

  • The command
  • Camera

#The command

cad model snapshot "$ID" tmp/review.png
cad model snapshot "$ID" tmp/top.png --camera top --display hidden-line
cad model snapshot "$ID" tmp/lid.png --part enclosure/lid --size 1600x1200

It draws the document as the server holds it (nothing is built) with a software renderer into a PNG, default 1024×768, isometric and shaded with edges. Open the PNG to look at it. From a script, await h.snapshot("tmp/review.png", { camera: "front", display: "hidden-line" }) does the same.

Keep review pictures in an ignored tmp/ folder, not beside the deliverables.

#Camera

--cameraLooks from
iso (default)Front-right-top, isometric
front / back-Y / +Y
left / right-X / +X
top / bottom+Z / -Z
x,y,zToward the model from that direction (1,-1,-0.5 is from the front-right, below)

The presets are the world's axes, Z up, not a part's own front: a plate modelled flat faces top and shows edge-on from front.

#Display

--displayDrawsUse for
shaded (default)Shaded faces with edge linesOverall form, placement, colours
hidden-lineVisible edges onlyProfiles, hole patterns, DXF outlines, counts
wireframeEvery edge, hidden ones tooInside features, which edges a selector will hit

#One part

--part PATH draws one part alone, by its path (enclosure/lid), at its place in the assembly. Use it for a part that the rest hides, and to review a part before the whole.

#What to look at

  • One picture is rarely enough. Look from the side that shows the change, and from the

    opposite side: an isometric hides the back, the bottom and anything inside.

  • For a hole pattern or outline, --camera top --display hidden-line and count.
  • For an assembly, each part alone, then the whole from front and back; a shell's inside

    needs wireframe or a section model.

  • A snapshot shows arrangement and appearance, never a number. A size, gap or wall comes from

    inspection.

  • A picture for the person is their open viewer page, which follows every run, or a photoreal

    cad model render (the render skill) for a README, a product shot or a turntable; snapshots are your own review.
