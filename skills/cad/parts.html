#Standard parts

Read this file when a model needs screws, nuts, washers, holes for them, bearings, gears, pulleys, extrusion or a stepper motor: parts in @cad/sdk makes them from their standards' tables instead of being modelled by hand, and each one carries a designation for the bill of materials.

import { assembly, box, model, parts } from "@cad/sdk";

export const joint = model("bolted_joint", () => {
  const plate = box(40, 30, 8, { align: ["center", "center", "max"] })
    .cut(parts.clearanceHole("M5", 8, { counterbore: true }))
    .label("plate", { material: "aluminum" });
  const cb = parts.tables.ISO4762.M5.k + 0.4;                     // the counterbore's depth
  return assembly("joint", [
    plate,
    parts.socketHeadScrew("M5", 25, { material: "stainless" }).translate(0, 0, -cb),
    parts.washer("M5").translate(0, 0, -8 - 1),
    parts.nylocNut("M5").rotateX(180).translate(0, 0, -8 - 1),
  ]);
});

parts.catalog() lists every maker with its standard and sizes; parts.tables holds the figures (parts.tables.ISO4762.M5.dk is 8.5, parts.tables.ISO273.M5.normal 5.5).

#Fasteners

Sizes M2 to M16, metric coarse. A screw's head bears on z = 0 and its shank runs down -Z; a countersunk head's top is at z = 0; a nut or a washer sits on z = 0 and rises +Z (turn a nut with .rotateX(180) to hang it under a plate).

MakerStandardDesignation
socketHeadScrew("M5", 20)ISO 4762ISO 4762 M5x20
hexBolt("M6", 30), hexBolt("M6", 60, { partial: true })ISO 4017, ISO 4014ISO 4017 M6x30
buttonHeadScrew("M4", 10)ISO 7380 (M3 to M16, no M14)ISO 7380 M4x10
countersunkScrew("M3", 12)ISO 10642 (length overall)ISO 10642 M3x12
setScrew("M4", 6)ISO 4026ISO 4026 M4x6
hexNut("M8"), nylocNut("M5")ISO 4032, ISO 10511ISO 4032 M8
washer("M6"), washer("M6", { chamfered: true })ISO 7089, ISO 7090ISO 7089 M6

Options: material (default steel; stainless, brass, nylon ...), color (by material), label (default screw_M5x20, nut_M5 ...; give each instance its own in an assembly), and for screws thread:

  • "cosmetic" (default): the shank is a plain cylinder at the pitch diameter, its tip chamfered.

    Light, and it clears a nut's bore (the major diameter) and a tapped hole: no false interference.

  • "modelled": an ISO 60 degree groove (full depth, 5H/8) cut along a helix into a blank at the

    major diameter, for a printed bolt or a picture. A second or two per screw on occt and cadrs, far longer on solidcore; the printing check reads its flanks as 30 degree overhangs.

#Holes for them

Cutters, to cut from a part: top at z = 0, running down -Z (and 0.5 mm above, for a clean cut).

CutterMakes

… { counterbore: true } / { counterbore: { d, depth } }DIN 974-1 for an ISO 4762 head (M5: 10 mm, head height + 0.4 deep)

… { point: true }a blind hole's 118 degree drill point

nemaHoles(17, thickness)a NEMA motor's pilot and four mounting holes

#Gears, racks and pulleys

const m = 2, mesh = parts.gearMesh(m, 18, 30);       // { distance: 48, turn: 6 }
const pinion = parts.spurGear({ module: m, teeth: 18, width: 8, bore: 8, dFlat: 7.5 });
const wheel = parts.spurGear({ module: m, teeth: 30, width: 8, bore: 12, keyway: { width: 4, depth: 1.8 } })
  .rotateZ(mesh.turn).translate(mesh.distance, 0, 0);
  • spurGear({ module, teeth, width, pressureAngle = 20, backlash = 0.05, bore, keyway, dFlat }):

    involute teeth (flanks through the involute, radial below the base circle), on z = 0. Its pitch diameter is module x teeth. gearProfile(...) is the 2D outline alone.

  • gearMesh(module, z1, z2): where the second gear goes along +X, and the turn that puts its gap

    opposite the first's tooth. Check a pair with cad model interference: the backlash keeps it clear.

  • rack({ module, length, width, height }): teeth up +Y, its pitch line at y = 0.
  • gt2Pulley(teeth, { belt = 6, bore = 5, hub = true }): GT2 2 mm pitch, flanges, a hub with an M3

    set-screw hole (20 teeth: 12.22 mm over the teeth).

#Bill of materials

Every standard part carries a designation; give your own parts one with .designate("...") or .label(name, { designation }).

const frame = assembly("frame", [...]);
frame.bom();   // [{ designation: "ISO 4762 M5x20", material: "stainless", count: 4, labels: [...] }, ...]
cad model bom "$ID"            # the same from the document: count, designation, material
cad model bom "$ID" --json

Parts are grouped by designation and material; a part with no designation is listed by its label.
