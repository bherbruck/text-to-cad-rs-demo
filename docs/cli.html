#cad command line

One Rust binary. cad <command> --help is the full interface.

CommandDoes
cad --versionVersion, kernel and kernel version
cad server start [--port 7878] [--kernel occt|solidcore] [--foreground]Starts the server (daemonised unless --foreground); writes ~/.cad/server.json
cad server status / cad server stop–
cad init [DIR]Writes package.json, tsconfig.json, src/example.ts and links node_modules/@cad/sdk
cad run SCRIPT.ts [ARGS…]Starts the server if needed, links the SDK if missing, runs the script with bun (else node), with CAD_SERVER_URL and CAD_TOKEN set. Exit code is the script's
cad model listDocuments: id, model, script, parts, updated
cad model inspect ID [REF] [--json]Parts, bounds, volume, mass; with a ref, one part/face/edge and made_by
cad model export ID FILE… [--tolerance MM] [--angle DEG] [--package NAME]Writes files by suffix: .step/.stp, .stl, .3mf, .glb, .obj, .dxf, .brep (kernel native), .pdf/.svg (engineering drawing, below), and robot descriptions .urdf, .xml/.mjcf (MuJoCo, with a scene.xml written once) and .srdf, their meshes beside them (robots). Unchanged files are not rewritten
cad model snapshot ID OUT.png [--camera iso] [--display shaded] [--size 1024x768] [--part PATH] [--pose POSE]Software-rendered picture. --camera also takes AZ:EL in degrees (45:30; 0:0 is the front) or x,y,z toward the camera. Size 16 to 8192 px

With --turntable: OUT.gif, or a PNG sequence into a folder (OUT/) or out_%03d.png. --json OPTIONS takes every option at once; flags override it. Prints wrote OUT (W×H, N spp, X.Xs)

cad model fea ID [--fix REF]… [--roller REF]… [--force 'REF:fx,fy,fz']… [--pressure 'REF:MPa']… [--gravity [gx,gy,gz]] [--material NAME] [--margin N] [--size MM] [--no-refine] [--study FILE|JSON] [--snapshot OUT.png] [--json]Stress check (crates/cad-fea: gmsh + CalculiX, docs/api.md "FEA"). #What cad run prints

Each model call (SDK) prints:

built src/bracket.ts::bracket in 0.41s: 12 ops, 9 hits, 3 misses
  parts 1 · bounds 40 × 20 × 6 mm · volume 4498.4 mm³
  id: 0dc50a92-a21f-5895-a245-ebdeb5352f3b
  view: http://127.0.0.1:7878/view/0dc50a92-…?token=…

On a failed build it prints error: <message> with at <src> and the script exits 1.

#DXF

.dxf export takes a model whose geometry is planar on z = 0 (faces or wires); it writes its edges as LINE / CIRCLE / ARC entities, splines as polylines. A 3D solid exports its section at z = 0.

#Poses

--pose takes a pose's name (open), joint values hinge=45,slide=10, or JSON joint values '{"hinge": 45}'; the joints left out stay as built. An unknown pose or joint, or a value outside a joint's limits, is refused (exit 2) by name.

#Output and exit codes

Results go to stdout; errors and progress to stderr. Every command that prints data takes --json and then prints exactly one line of JSON; a failure under --json also prints {"ok": false, "error": "…"} on stdout. Exit 0 is success, 1 is a "no" answer (a failed build, interference), 2 a refused command (usage, bad options, no server, unknown document).

#Drawings

.pdf and .svg export an engineering drawing of the model (docs/api.md, "Drawings"):

cad model export "$ID" drawings/bracket.pdf --sheet A3 --projection third --date 2026-11-23 \
  --part-number BR-001 --general-tolerance "ISO 2768-m" --note "BREAK SHARP EDGES."
FlagDefault
--sheet A4|A3|A2|A1|A0A3 (landscape)
--projection third|firstthird
--views top,front,right,isothose four (front top right left bottom back iso)
--scale 0.5the largest standard scale that fits (refused, naming one that fits, if too large)
--title, --part-number, --material, --revision, --authormodel name, –, the parts' materials, A, –
--datetoday
--note TEXT (repeatable), --general-tolerance ISO 2768-m–
--no-hidden, --no-dimensions, --part PATH–

Drawing flags are refused for other formats, as --tolerance/--angle are for non-mesh ones.
