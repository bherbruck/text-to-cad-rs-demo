#Licences

An engineering summary, not legal advice. scripts/check-licenses.sh keeps the dependency part current: it lists every package that ships, flags any licence MIT OR Apache-2.0 distribution cannot carry, and writes THIRD_PARTY_NOTICES.md. Run it after adding a dependency; --check fails when a licence is flagged or the notices are out of date.

#This project

Every crate, the SDK, the viewer and the skills: MIT OR Apache-2.0 (LICENSE-MIT, LICENSE-APACHE, NOTICE).

#External tools cad runs (not linked, not shipped)

cad starts these as separate programs when present on PATH; it does not link, bundle or redistribute them, so their licences bind their distributors, not ours. A user installs them.

ToolUsed byLicence
bun or Node.jscad run (runs the model script)MIT
gmshcad model fea (meshing)GPL-2.0-or-later (with linking exceptions)
CalculiX ccxcad model fea (solving)GPL-2.0
KiCad kicad-clicad pcb erc|drc|export|step|writeGPL-3.0-or-later
MuJoCo (Python)cad mujoco check's optional compileApache-2.0
ROS check_urdfan optional test onlyBSD-3-Clause

Talking to a GPL program over its command line and files is not linking; keep it that way: never vendor, embed or statically link gmsh, CalculiX or KiCad into cad.

#Development only (not shipped)

TypeScript, Vite, Vitest, Playwright, testing-library and the other dev dependencies of packages/sdk and apps/viewer, and cargo's dev-dependencies (png, the OCCT adapter in cad-engine's tests). They do not reach a release.

#Findings of the audit (2026-11-23)

  • No GPL, AGPL or LGPL crate or npm package in what ships; OCCT is the only LGPL component and is

    kept a separate module as its licence requires.

  • One weak-copyleft crate, option-ext (MPL-2.0), and only inside a proc macro at build time: acceptable, noted.
  • Every package declares a licence.
  • A release (scripts/build.sh) ships LICENSE-*, NOTICE, THIRD_PARTY_NOTICES.md, the OCCT

    licence texts and docs-occt-LICENSING.md beside the binary.
