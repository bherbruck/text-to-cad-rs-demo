#Installing text-to-cad-rs

One command installs cad and sets up the agent plugin in every agent app on the computer.

macOS and Linux:

curl -fsSL https://github.com/bherbruck/text-to-cad-rs/releases/latest/download/install.sh | sh

Windows, in PowerShell:

irm https://github.com/bherbruck/text-to-cad-rs/releases/latest/download/install.ps1 | iex

cad run needs bun or Node 22.6+ on your PATH to run model scripts. FEA wants gmsh and CalculiX (ccx), circuit boards kicad-cli: each is found when it is used.

#What it does

  1. Picks the archive for this machine from the release's SHA256SUMS: Linux x86_64 or aarch64,

    macOS arm64 or x86_64, Windows x86_64 (cad-<version>-<target>.tar.gz, .zip on Windows).

  2. Downloads it and checks its SHA-256 against SHA256SUMS; a mismatch stops it before anything is

    installed.

  3. Installs into ~/.cad (or --prefix): bin/cad with the OCCT module beside it

    (libocct_capi.so, .dylib, or occt_capi.dll, found next to the binary) and bin/wasm/ (the browser engines the viewer's playground loads: OCCT and solidcore, about 7.8 MB and 8.9 MB compressed), the plugin into plugin/, licences into share/, and itself into install/ for --update and --uninstall. ~/.cad is also where cad keeps its server state and saved documents. The binary has OCCT (the default) and the solidcore kernel: cad server start --kernel solidcore.

  4. Sets up the plugin in each agent app it finds, with that app's own mechanism (below). Every MCP

    entry runs the installed cad by its full path, so it works before PATH is set.

  5. Says what to add to PATH, or with --modify-path adds it: on macOS and Linux one marked block in

    your shell's profile (~/.zshrc, ~/.bashrc, ~/.bash_profile on macOS, fish's config.fish, else ~/.profile); on Windows your user PATH. Without the flag it changes nothing and prints the exact line.

It never overwrites an app's configuration that is not ours: a skill folder or a cad MCP server that is someone else's is left as it is, with a warning. A file it adds to is backed up beside itself first (config.toml.bak.<time>). Every change is recorded in ~/.cad/integrations, which --uninstall undoes.

#Options

Option (install.sh / install.ps1)Does
--version V / -Version VThat release instead of the latest
--prefix DIR / -Prefix DIRInstall into DIR (CAD_PREFIX too)
--release-url U / -ReleaseUrl UA folder holding SHA256SUMS and the archives, https:// or file:// (CAD_RELEASE_URL too): a mirror, or a local build
--modify-path / -ModifyPathAdd PREFIX/bin to PATH
--no-apps / -NoAppsLeave agent apps alone
--update / -UpdateUpdate an existing install: binary, engines, plugin, app entries
--uninstall / -UninstallUndo everything it recorded and remove what it installed; keeps ~/.cad's documents
--purge / -PurgeWith --uninstall, also remove ~/.cad
--dry-run / -DryRunSay what it would do; download and change nothing

To update or uninstall later, run the installed copy: sh ~/.cad/install/install.sh --update (PowerShell: & ~\.cad\install\install.ps1 -Update).

#From a local build

scripts/build.sh                                        # dist/cad-<version>-<target>.tar.gz + SHA256SUMS
sh scripts/install/install.sh --release-url "file://$PWD/dist"

#By hand

Unpack the archive anywhere, keep cad, the OCCT module and wasm/ together, and put that folder on PATH. Then point each agent app at the plugin: Claude Code claude plugin marketplace add bherbruck/text-to-cad-rs and claude plugin install text-to-cad-rs@bherbruck; any MCP client: a server named cad running cad mcp.

#Releases

.github/workflows/release.yml builds on a v* tag:

  • A cad archive for each of five targets. Each target is tested (scripts/test.sh fast; on Windows

    cargo test) and packaged by scripts/build.sh.

  • The browser engines (OCCT and solidcore; the experimental cadrs engine is not shipped), built once

    and shared.

  • The static site, from the Linux build.

It then opens a draft release with the archives, SHA256SUMS, install.sh and install.ps1. A person publishes it.

The OCCT module is built from source per target (8 minutes to an hour) and cached on the hash of crates/occt-capi-sys/capi/, so only a change there rebuilds it.

#Tests

scripts/install/test.sh runs without a network in a temporary HOME, against a fake release built from a stub cad. It checks seven things:

  • shellcheck passes.
  • --dry-run changes nothing.
  • An install places every file and sets up every app.
  • A corrupted archive is refused.
  • --update is idempotent.
  • Config that is not ours is left alone.
  • --uninstall restores every config byte for byte, and --purge removes the prefix.

It also checks that install.ps1 parses and dry-runs where pwsh is installed. CI's installer job runs it.
