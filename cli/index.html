CLI reference

The full contract is in Command line. Every page here is --help, captured from the binary when the site was built.

cad --help

  • cad server Start, stop or check the local server
  • cad server start Start it (in the background unless --foreground)
  • cad server status Is it running?
  • cad server stop Stop it
  • cad init Write a starter project: package.json, tsconfig.json, src/example.ts, the SDK
  • cad run Run a model script: starts the server if needed, links the SDK, runs with bun or node
  • cad model Act on a model's document
  • cad model list Documents on the server
  • cad model inspect Parts, bounds, volume, mass; with a ref, one part, face or edge and what made it
  • cad model export Write files by suffix: .step .stl .3mf .glb .obj .dxf .brep
  • cad model snapshot A picture, rendered on the server
  • cad model interference Pairs of parts that share volume; exits 1 if any (or if a pair could not be checked)
  • cad model bom Bill of materials: the parts grouped by designation (standard parts' "ISO 4762 M5x20"; a part without one by its label) and material, with counts
  • cad model dfm Can it be made? A manufacturing check: OK (exit 0), FAILED (1), NOT CHECKED (3)
  • cad model fea Stress check (linear static FEA: gmsh + CalculiX). With no fixtures or loads, lists the faces to choose from
  • cad model render A path-traced picture (draft by default; --preset final for the finished look), or a turntable as a GIF or a PNG sequence
  • cad model ranges Each joint's stops, found by moving it until its parts meet; changes nothing
  • cad viewer Open STEP/STL files as documents and print their pages (no file: the index page)
  • cad step Act on a STEP or STL file (opened as a document)
  • cad step dfm Can it be made? The manufacturing check of the file's parts (see `cad model dfm`)
  • cad mcp MCP server on stdio
  • cad pcb cad pcb: KiCad boards and schematics
  • cad urdf Check a URDF (hand-written or exported with `cad model export ID robot.urdf`)
  • cad urdf validate The tree, joints, limits, geometry, meshes and inertials; exit 1 if the file fails
  • cad srdf Check an SRDF against the URDF beside it
  • cad srdf validate Every group, chain, state, end effector and collision pair against the URDF's names
  • cad mujoco Check an MJCF (a robot.xml or the scene.xml that includes it)
  • cad mujoco check Names, meshes, masses, inertias, ranges and keyframes; MuJoCo's own compile where `python3 -c "import mujoco"` works
