cad model

Act on a model's document

Act on a model's document

Usage: cad model <COMMAND>

Commands:
  list          Documents on the server
  inspect       Parts, bounds, volume, mass; with a ref, one part, face or edge and what made it
  export        Write files by suffix: .step .stl .3mf .glb .obj .dxf .brep
  snapshot      A picture, rendered on the server
  interference  Pairs of parts that share volume; exits 1 if any (or if a pair could not be checked)
  bom           Bill of materials: the parts grouped by designation (standard parts' "ISO 4762 M5x20"; a part without one by its label) and material, with counts
  dfm           Can it be made? A manufacturing check: OK (exit 0), FAILED (1), NOT CHECKED (3)
  fea           Stress check (linear static FEA: gmsh + CalculiX). With no fixtures or loads, lists the faces to choose from
  render        A path-traced picture (draft by default; --preset final for the finished look), or a turntable as a GIF or a PNG sequence
  ranges        Each joint's stops, found by moving it until its parts meet; changes nothing
  help          Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
