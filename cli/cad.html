cad

Design physical products with AI: TypeScript models, a B-rep kernel, a live viewer.

Design physical products with AI: TypeScript models, a B-rep kernel, a live viewer.

Usage: cad <COMMAND>

Commands:
  server  Start, stop or check the local server
  init    Write a starter project: package.json, tsconfig.json, src/example.ts, the SDK
  run     Run a model script: starts the server if needed, links the SDK, runs with bun or node
  model   Act on a model's document
  viewer  Open STEP/STL files as documents and print their pages (no file: the index page)
  step    Act on a STEP or STL file (opened as a document)
  mcp     MCP server on stdio
  pcb     KiCad boards and schematics: inspect, erc, drc, export, step, write (`cad pcb --help`)
  urdf    Check a URDF (hand-written or exported with `cad model export ID robot.urdf`)
  srdf    Check an SRDF against the URDF beside it
  mujoco  Check an MJCF (a robot.xml or the scene.xml that includes it)
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
