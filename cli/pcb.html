cad pcb: KiCad boards and schematics

cad pcb: KiCad boards and schematics

  cad pcb inspect FILE [--json]              a board or schematic in one look (no KiCad needed)
  cad pcb erc FILE [--json]                  KiCad's ERC (a schematic, or the board's schematic)
  cad pcb drc FILE [--json] [--parity] [--refill]
                                             KiCad's DRC (--parity: against the schematic;
                                             --refill: zones refilled first, on a copy)
  cad pcb export FILE KIND... [--out DIR] [--json]
                                             fabrication outputs: gerbers, drill, pos, bom, pdf,
                                             sch-pdf, svg, step, netlist (default DIR: <name>-fab)
  cad pcb step FILE [--out FILE.step]        the board and its parts as STEP
  cad pcb route FILE [--out FILE] [--width MM] [--clearance MM] [--pitch MM] [--nets A,B] [--json]
                                             route the board's nets (pours: fan-out vias), then
                                             refill and DRC it with KiCad
  cad pcb write DESIGN.json [--out DIR] [--fill] [--json]
                                             a design (@cad/sdk's pcb) written as a KiCad project;
                                             --fill refills its zones with KiCad

Exit codes: 0 done, 1 ERC/DRC errors, 3 could not run.
